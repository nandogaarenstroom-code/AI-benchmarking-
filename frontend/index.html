Start llama.cpp server (Windows)

The app can start a local llama-server on 127.0.0.1:8080. You must already have a GGUF model file. Context size is a requested startup value, not a promise that the model or your hardware can support it.

WinGet does not launch apps itself; this option locates llama-server.exe inside an already-installed WinGet package. Enter that package's ID (including a custom-fork package ID). High context sizes or GPU offload settings can exceed available memory. This app-managed server uses port 8080.

Security: only launch an executable you trust. It runs with the same permissions as this app.

Test-by-test results

Review every prompt, difficulty, model answer, evaluator check, and retry. This is the observable evidence used for scoring—not private chain-of-thought.

Difficulty labels are task-construction tiers, not calibrated estimates of human or model difficulty. The top pilot tier is labeled Uncalibrated.

The per-test model-relative meter shows this model's evaluator score and repeat consistency for this run only. It is not a universal or calibrated difficulty rating; demo results do not measure model ability, and unrun tests are not treated as failures.
